# 数据与登录凭据

本客户端通过学校选课接口读取账号、轮次和课程信息，并按用户操作提交选退课请求。客户端未配置自有业务后端或分析统计服务。

原生 GUI 使用 flutter_secure_storage 提供的平台安全存储保存 Token。Web 使用浏览器 WebCrypto 加密存储，需要 HTTPS 或 localhost；浏览器中运行的页面仍能读取登录状态。其他偏好、课程目标、操作状态和运行日志保存在当前设备。

旧版保存在 SharedPreferences 中的明文 Token 会在初始化时删除，不自动迁移，请重新登录。退出登录会删除客户端安全存储中的 Token；学校网页登录组件的会话由其浏览器/WebView 管理。

GUI 导出的 Base64 配置包含 Token、学生/轮次/学期标识和课程目标，用于交给 CLI 执行。Base64 可以解码，命令行历史、剪贴板和可读取进程参数的软件可能接触到该配置。不要公开配置字符串。CLI 不把 Token 写入运行状态文件。

报告问题时请只附上已检查并去除个人信息的日志。删除客户端数据不会撤销已经向学校提交的选课操作；选课状态以学校系统为准。
